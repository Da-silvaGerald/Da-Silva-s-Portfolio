## Short Description
**My Portfolio: Da-Silva Oluwasegun** is a personal software engineering and cybersecurity portfolio website built for **CSC 419** at Pan-Atlantic University. Designed with a dark security-operations console aesthetic, it showcases my background, my Oando Energy Resources IT internships (Summers 2025 & 2026), my focus areas in defensive/offensive security and IAM, and dedicated architectural case studies for **Udemy 50 Projects**, **CafeteriaApp**, and **SanteDiagnostics (LIMS)**.

## Tech Stack
- **React 18 + TypeScript + Vite**
- **React Router v6** (`BrowserRouter` with dynamic `/projects/:slug` routes and a custom 404 console page)
- **Plain CSS with Custom Properties** (centralized design tokens in `src/styles/tokens.css` and component-scoped CSS; zero Tailwind or component libraries)
- **Google Fonts:** `Archivo` (headings/display) and `IBM Plex Mono` (telemetry, logs, and metadata)

## How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Da-silvaGerald/shegz419.git
   cd shegz419
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Test the production build locally:**
   ```bash
   npm run build
   npm run preview
   ```
